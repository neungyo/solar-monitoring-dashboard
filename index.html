☀️ Solar Monitoring Dashboard — Synnex Thailand

เวอร์ชันสาธารณะ (Public) — ตัดชื่อ (เหลือแค่ชื่อจริงบางส่วน), ที่อยู่, เบอร์โทร/อีเมลลูกค้า และพิกัด GPS ออกแล้ว เพื่อไม่ให้ข้อมูลส่วนบุคคลของลูกค้าเผยแพร่บนอินเทอร์เน็ตสาธารณะ
ข้อมูลนี้ อัปเดตอัตโนมัติทุก 15-30 นาที ผ่าน GitHub Actions (ดึงสดจาก Huawei FusionSolar Northbound API) — แค่รีเฟรชหน้านี้ก็เห็นข้อมูลล่าสุดที่ระบบดึงมาได้เลย ไม่ต้องแจ้งในแชท
ขอบเขต: เฉพาะ 37 สถานีของ Synnex Thailand ที่บัญชี API นี้เข้าถึงได้ — ยังไม่รวม shared plants (~30 สถานีที่เหลือจากทั้งหมด 67)
ข้อจำกัดของ API: ข้อมูลระดับ PV string (PV1-8) แบบย้อนหลังรายวันไม่มีให้ผ่าน Northbound API — มีเฉพาะค่าปัจจุบัน (real-time) เท่านั้น ส่วนย้อนหลัง 10 วันระดับ string ใช้ค่า performance ของแต่ละ inverter แทน
