☀️ Solar Monitoring Dashboard — Synnex Thailand

เวอร์ชันสาธารณะ (Public) — ตัดชื่อ (เหลือแค่ชื่อจริงบางส่วน), ที่อยู่, เบอร์โทร/อีเมลลูกค้า และพิกัด GPS ออกแล้ว เพื่อไม่ให้ข้อมูลส่วนบุคคลของลูกค้าเผยแพร่บนอินเทอร์เน็ตสาธารณะ
ข้อมูลนี้อัปเดตผ่าน Cowork scheduled task ที่ดึงสดจาก Huawei FusionSolar Northbound API แล้ว push ขึ้นหน้านี้โดยตรง (ไม่ใช่ GitHub Actions — ถูกบล็อกด้วยข้อจำกัด geo-DNS ของ Huawei) รีเฟรชตามรอบที่ตั้งไว้ หรือสั่งรีเฟรชครั้งเดียวได้ผ่านแชท
ขอบเขต: เฉพาะ 37 สถานีของ Synnex Thailand ที่บัญชี API นี้เข้าถึงได้ — ยังไม่รวม shared plants (~30 สถานีที่เหลือจากทั้งหมด 67)
ข้อจำกัดของ API: ข้อมูลระดับ PV string (PV1-8) แบบย้อนหลังรายวันไม่มีให้ผ่าน Northbound API — มีเฉพาะค่าปัจจุบัน (real-time) เท่านั้น ส่วนย้อนหลัง 10 วันระดับ string ใช้ค่า performance ของแต่ละ inverter แทน ส่วน PV1/PV2 ด้านล่างเป็นกราฟรายชั่วโมงของวันนี้ (รีเซ็ตทุกเที่ยงคืน)
